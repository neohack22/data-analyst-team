# Data Analyst Team

This repository contains data analysis tools and resources for the data analyst team.

## Contents

- **Hello.py** - A simple Python script that demonstrates basic Python output
- **DataIngestToCassandra.ipynb** - Jupyter notebook for ingesting data into Apache Cassandra
- **1_final MSR_7MAR.pdf** - Market research documentation

## Requirements

- Python 3.x
- Jupyter Notebook (for running the .ipynb file)
- Apache Cassandra (for data ingestion notebook)

## Usage

### Running Hello.py

```bash
python3 Hello.py
```

### Running the Jupyter Notebook

```bash
jupyter notebook DataIngestToCassandra.ipynb
```

## Project Description

This project provides tools and documentation for data analysis tasks, including:
- Data ingestion pipelines to Cassandra database
- Market research analysis and documentation
- Basic Python utilities
